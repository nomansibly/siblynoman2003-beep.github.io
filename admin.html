Publish your update

  1. Click Copy updated page below.
  2. Open the GitHub editor and sign in to your account if asked.
  3. Select all text inside GitHub’s file editor and paste the copied page.
  4. Click Commit changes. GitHub Pages deploys the update automatically, usually within a few minutes.

Open GitHub editor ↗

Alternative: download index.html above, then use GitHub → Add file → Upload files to replace it. Saving a browser draft does not publish it. Anyone can open this editor; only authorized GitHub collaborators can publish to your repository.

Drafts stay in this browser’s local storage; they do not sync across devices. Download a backup before clearing browser data. Restoring an older draft replaces the current editing session, so reload the page to start from the latest published version.
